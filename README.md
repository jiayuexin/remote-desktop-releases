# Remote Desktop 安装包

这里只放**安装包下载**，源码在私有仓库，不公开。

## 下载

打开 [Releases](https://github.com/jiayuexin/remote-desktop-releases/releases) 选择版本下载。

### v0.1.0（Mac 桌面控制端）

- Apple Silicon（M 系列）：`rd-desktop-0.1.0-mac-arm64.dmg`
- Intel Mac：`rd-desktop-0.1.0-mac-x64.dmg`

Windows 被控端安装包后续会发到同一 Releases 页。

未签名包，适合自用/内测；首次打开若提示无法验证，可在系统设置里仍要打开，或右键打开。
